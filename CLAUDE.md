build system, application code, or test suite yet.

## Working in This Repo

- This is a demo/lab project; keep experiments self-contained and well-labeled.
- When adding code, introduce the relevant tooling (package manifest, lockfile,
  test runner) alongside it, and update this file with the build/test/run
  commands so future sessions can discover them.
- Update the structure section above when you add new top-level files or
  directories.

## Conventions

- Prefer small, focused changes that match the surrounding style.
- Document new experiments in the README so the repo stays self-explanatory.
